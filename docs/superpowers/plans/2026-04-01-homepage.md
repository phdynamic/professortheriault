# ProfessorTheriault.com Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a static homepage for ProfessorTheriault.com with a hero section, 5 course/project cards with hover effects, and responsive layout.

**Architecture:** Single `index.html` file with all CSS embedded in a `<style>` block. No JavaScript, no external dependencies. CSS Grid for card layout, CSS transitions for hover effects, media queries for responsiveness.

**Tech Stack:** HTML5, CSS3 (Grid, transitions, media queries). No build tools or frameworks.

---

## File Structure

- **Create:** `index.html` — the entire homepage (HTML structure + embedded CSS)

That's it. One file.
